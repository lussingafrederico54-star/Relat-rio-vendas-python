# Relatório-vendas-python
Sistema de Relatório de Vendas em Python Automatizei a geração de relatórios PDF a partir de planilha Excel.  O que faz: - Lê estoque em Excel (pandas) - Calcula total gerado: 6840 Kz - Gera PDF automático com fpdf2  Tecnologias: Python, Pandas, FPDF Feito no celular com Pydroid3
